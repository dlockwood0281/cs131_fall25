LLMs - How they answer prompts:
  This presentation is about how LLMs answer prompts. It goes through the training stages and how it is introduced to datasets to help it give more accurate responses. The main part of the presentation goes over RAG and CAG, which are augmented generation methods that LLMs use when prompts ask for information not included within its training data. Pros and cons for both methods are also elaborated on.<br/>
